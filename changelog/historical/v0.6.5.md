Changes since v0.6.2.

## Playing and installation

- Linux releases include AppImage, Debian and RPM installers. (#191)
- One client instance handles additional launches and replay-file associations. (#215)
- Keep the join progress dialog open until the game starts, with a Cancel action. (#202)
- Enforced host rating ranges reject players outside the configured range. (#215)
- Resize the game list and its details panel. (#215)
- Sort the game list using its column headers. (#239)
- Column resizing no longer imposes an upper width limit. (#279)
- A completed game uploads its replay to FAF instead of keeping it only on disk. (#275)
- Replay uploads survive a dropped connection without truncating the replay. (#275)

## Replays

- Browse live replays in a grid or a list, with a separate remembered view choice. (#241)
- Replay analysis shows army details, activity graphs and recorded statistics. (#246)
- Search replay chat and filter it by channel. (#246)
- Watch or download a replay directly from its grid card. (#246)
- Replay startup shows progress and can be cancelled. (#260)
- The local replay archive refreshes when opened and shows recorded game duration. (#260)
- Filter local replays by game mode. (#260)
- Live replay details can enlarge the map and load the players' profiles. (#241)
- Replay launches close the previous replay before starting another copy of that install. (#271)

## Settings, maps, mods and chat

- Settings are divided into navigable sections. (#277)
- Set a delay for hover panels or disable them. (#266)
- Choose custom notification sounds and the built-in FAF match-found sound. (#202)
- Limit the number of generated maps retained on disk. (#215)
- Favourite installed mods and enable the selected set together. (#239)
- Mod searches prioritise matches in the mod name. (#246)
- Group clanmates in the chat roster. (#271)
- Mentions are shown to the sender and recipient rather than colouring the entire room. (#202)
- Game tiles indicate friends and foes in their lobbies. (#275)
- The leaderboards combine queue ratings in one table. (#246)
- German, Russian, French, Spanish and Polish translation catalogues were completed. (#215)
