Changes since v0.6.0.

## Maps, mods and playing

- Zoom and pan large map previews throughout the client. (#134)
- Copy a map preview image, with a link fallback when image copying is unavailable. (#134)
- Update an installed mod in one action. (#133)
- Find maps in the host dialog's Favourites tab. (#152)
- Open games indicate which ones contain your friends. (#132)
- Joining shows required simulation mods and asks before downloading them. (#152)
- Join preparation shows the download size and describes its current work. (#152)
- Map-generator options are remembered automatically, and map names can be edited. (#167)
- Saved matchmaking vetoes are restored when the server does not retain them. (#167)
- The client reconnects to the lobby after a lost connection. (#167)
- A match that never starts eventually releases the matchmaking controls. (#167)

## Replays, ratings and chat

- Mark replays as watched, undo that mark and filter by watched status. (#131)
- Filter online replays by the number of players. (#152)
- Filtered replay pages fill with matching results instead of stopping at an internal page-size limit. (#152)
- Jumping to a later page of a large local replay archive shows the replays, not only file names. (#127)
- The leaderboard includes a rating explanation based on the FAF wiki. (#136)
- Game lineups use the rating for the game mode being played. (#167)
- Negative ratings are displayed as ratings rather than replaced with zero. (#167)
- Right-click a chat message to quote it in a reply. (#167)
- Replay chat identifies each speaker without duplicating their lines. (#167)

## Notifications and desktop support

- Notifications can appear as corner toasts with selectable tones and volume previews. (#152)
- Set the sidebar width in Appearance settings. (#152)
- Linux support adds a Wine launch wrapper and Linux game-folder discovery. (#154)
- Watching a replay no longer closes the game running in the separate game install. (#152)
- Map and mod reporting links provide a route to report offensive content. (#167)
- Narrow windows can scroll content that no longer fits. (#152)
