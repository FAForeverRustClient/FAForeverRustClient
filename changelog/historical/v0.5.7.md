Changes since v0.5.6.

## Training

- Browse a community-maintained catalogue of guides, videos and trainers in the new Training hub. (#64)
- Get training recommendations using the rating for each resource's game mode. (#64)
- Submit training resources and request replay reviews from the client. (#64)

## Replays and mods

- Settings, Game includes an optional Windows live-replay workaround using a named pipe. (#61)
- Joining asks before replacing an installed simulation-mod version that conflicts with the host's version. (#61)
- Replay lineups show rating changes from the rating journal. (#62)
- Unrated replays explain why they were not rated. (#62)
- Replay details list simulation mods recorded in the replay header. (#62)

## Fixes

- Hosting without a password no longer advertises a locked game. (#62)
- Opening a private conversation selects it even when its channel is still joining. (#62)
- Nickname completion no longer inserts an extra colon. (#62)
- Generated-map previews can be opened at full size. (#62)
