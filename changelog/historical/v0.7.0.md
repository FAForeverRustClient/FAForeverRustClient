Changes since v0.6.5.

## Playing and matchmaking

- Dynamic connectivity selects the adapter used by the host. (#354)
- Choose separate connectivity preferences for joining and hosting. (#354)
- Recent matchmaking games are available in a table with adjustable columns. (#338)
- Party seats display every faction selected by each player. (#346)
- The party leader can leave the party. (#346)
- An optional notification announces a suitable opponent joining a matchmaking queue. (#347)
- The matchmaking panel no longer remains stuck on Starting your match. (#308)
- Cancelling host preparation stops the pending host request. (#352)
- First-time FAF game setup includes the required BugSplat library. (#332)

## Replays and player profiles

- Keep private notes and tags on replays. (#338)
- Manage replay tags and filter the archive by them. (#338)
- Choose friends from a list when filtering replays. (#346)
- Replay lineups can show country flags. (#338)
- Player searches and leaderboard searches can find former account names. (#338)
- Player profiles include a Results tab listing their games. (#348)
- Report a player who is currently offline. (#338)
- Unrated replays can show a winner when the recorded outcome is decisive. (#346)
- Watching a modded replay restores your previous enabled-mod selection afterwards. (#348)
- Rate a replay directly from its stars. (#352)
- Generate a missing map preview from the live replay list. (#352)

## Reliability and interface

- Fresh installations start in the system language when a translation is available. (#308)
- An unreadable settings value no longer resets every setting. (#332)
- Generated maps use the configured maps folder. (#332)
- Linked mod folders and nested mod folders are detected. (#308)
- League seasons include every placed player rather than only the first hundred. (#332)
- Review counts and ratings include the submitted review. (#352)
- Linux finds co-op maps and game preferences regardless of filename case. (#349)
- Dates use the Windows regional format. (#350)
- Adjustable-column lists retain their columns while fitting the available width. (#347)
- Chat game cards provide Join game and Watch live actions. (#352)
